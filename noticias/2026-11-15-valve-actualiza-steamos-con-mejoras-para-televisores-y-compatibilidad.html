Valve actualiza SteamOS con mejoras para televisores y compatibilidad con Nvidia

Una nueva actualización de SteamOS optimiza el sistema para pantallas de televisión y amplía las capacidades para tarjetas gráficas Nvidia. El movimiento acerca el software de Steam Deck a más configuraciones de PC.

Por qué te importa

Facilita convertir cualquier ordenador con gráfica Nvidia en una consola de salón sin depender de Windows, ampliando las opciones para jugar en el televisor.
